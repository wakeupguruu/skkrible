# Friends-only game contract

The first version targets about 100 simultaneous friends across private rooms, with 2–20 seats per room. The frontend is a static Vercel build. Each backend room will be one SQLite-backed Cloudflare Durable Object. There is no shared global leaderboard or account system.

The server owns turns, words, hints, deadlines, and scores. Correct guesses earn 100–500 points based on remaining server time; each correct guess earns the drawer 50 points. The browser never receives other players' resume credentials or the answer before guessing/reveal. These are our game's rules, not a claim about skribbl.io's scoring.

The host chooses 1–5 candidate words, a built-in difficulty pool (`easy`, `normal`, `hard`), and 0–5 letter hints. Custom lists are no longer used, including in previously saved rooms. Empty legacy custom-word fields remain in views so already-open clients do not crash before refreshing. Hints arrive at fractions `i / (hints + 1)` of the drawing duration, capped so the final non-space character remains hidden. Views expose `hintsRevealed`, `hintCount`, and `nextHintAt` for countdown display. Legacy rooms/clients default to three choices and normal difficulty.

Guesses use the existing `chat` command only during an active drawing turn. Wrong guesses are not added to shared messages. Their acknowledgement has a private `feedback` value of `close` or `miss`; close means one normalized character inserted, deleted, substituted, or one adjacent pair transposed. Only the requesting socket receives this feedback. Shared views expose only `correct` notifications naming the player who guessed, without the answer or points. Each public player view includes `turnPoints`; these reset when the next drawer is selected and remain visible during the six-second result phase. The result screen and timer position show turn earnings separately from total scores.

Avatars are bounded integer IDs 0–799 encoding eight colors, five eye styles, five mouths, and four accessories. The shared codec validates the representation; browser-generated SVG uses only local fixed markup and palette values. Existing IDs 0–7 remain valid.

Commands have a random `id`, a `type`, and, for turn-specific actions, a `turnId`. The server retains recent command receipts so replaying an acknowledged or uncertain command cannot double-score or duplicate a drawing. A completed stroke also has its own ID, making stroke retries independent of the receipt window. The client must not carry unsent strokes into another turn.

Commands: `settings`, `start`, `choose`, `chat`, `stroke`, `undo`, `clear`, `voteKick`, and `leave`. Direct `kick` commands are rejected for everyone, including the host. Live ink previews are transient; completed strokes and game state are durable before acknowledgement. State views and drawing data are separate, so ordinary score/guess updates do not retransmit the whole board. Snapshots contain the complete committed drawing for resynchronization.

A vote snapshots the other connected player IDs as its electorate. Its threshold is a strict majority of those seats, with a minimum of two, so voting requires at least three connected players. The host has one vote. A voter cannot vote for themselves or increase their count through retries/new command IDs. The electorate and threshold remain fixed for 60 seconds; disconnecting or adding seats does not lower the requirement, and late joiners wait for the next vote. Explicitly leaving removes that player's cast votes. Votes and their expiry persist across reconnection and room reload. A successful vote removes the target's seat/token and immediately reveals an active drawer's interrupted turn. This removes a room seat; it is not a permanent account ban.

A resume token restores the existing seat and score for the room's lifetime. Disconnecting preserves that seat. Another online player becomes host when necessary. A drawer has up to 30 seconds to reconnect, bounded by the remaining turn time. If everyone disconnects, the game pauses and can resume once two players return. Explicitly leaving or being removed releases the seat. Rooms expire after 24 hours without accepted game commands or joins; this is per-room session storage, not permanent player history.

Limits: 160-character guesses, 1,200 committed strokes or 40,000 drawing points per turn, and 2,048 points per stroke. The UI splits long gestures into bounded strokes. Only the drawer can change the board, and only the host can change room settings or start a game.

Free hosting is a budget constraint, not an uptime guarantee. Cloudflare's free Durable Objects tier has daily compute and storage-operation quotas; exhausted quotas reject operations. Paid services will not be enabled automatically. Local 100-client verification will measure the implementation rather than certify hosted free-tier capacity.
